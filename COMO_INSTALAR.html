Criar conta no Firebase (Google) — Gratuito

O Firebase é um serviço do Google que vai guardar todos os dados da loja com segurança. É 100% gratuito para o tamanho da sua loja.

✅ Você já tem conta no Google? Então já tem acesso ao Firebase!
🔗 Abrir Firebase Console

Clique no link acima e faça login com a conta Google da Sara.

2

Criar um novo projeto Firebase

Dentro do Firebase Console:

  • Clique em "Adicionar projeto" (ou "Create a project")
  • Nome do projeto: sara-her-makeup
  • Desative o Google Analytics (não precisa)
  • Clique em "Criar projeto"
  • Aguarde criar e clique em "Continuar"
📸 Você verá a tela principal do projeto com o nome "sara-her-makeup"
3

Configurar o Banco de Dados (Firestore)

O Firestore é onde todos os produtos, pedidos e dados financeiros ficam salvos na nuvem.

  • No menu lateral esquerdo, clique em "Firestore Database"
  • Clique em "Criar banco de dados"
  • Selecione "Iniciar no modo de produção"
  • Escolha a localização: southamerica-east1 (São Paulo)
  • Clique em "Ativar"
⚠️ Após criar, precisamos configurar as regras de segurança. Veja abaixo:

Configurar Regras de Segurança:

Clique na aba "Regras" dentro do Firestore e cole o código abaixo:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Produtos: qualquer um pode ler, só admin escreve
    match /produtos/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    // Pedidos: qualquer um pode criar, só admin lê/edita
    match /pedidos/{id} {
      allow create: if true;
      allow read, update, delete: if request.auth != null;
    }
    // Caixa e Config: só admin
    match /caixa/{id} {
      allow read, write: if request.auth != null;
    }
    match /config/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Clique em "Publicar" para salvar as regras.

4

Criar o login do Admin (Authentication)

Vamos criar o e-mail e senha que a Sara vai usar para entrar no painel administrativo.

  • No menu lateral, clique em "Authentication"
  • Clique em "Começar"
  • Clique em "E-mail/senha" e ative a opção
  • Clique em "Salvar"
  • Vá na aba "Usuários"
  • Clique em "Adicionar usuário"
  • E-mail: o e-mail da Sara
  • Senha: escolha uma senha segura
  • Clique em "Adicionar usuário"
✅ Guarde bem o e-mail e senha! Eles serão usados para entrar no painel admin.

Obter as credenciais do Firebase

Agora vamos pegar as informações que o sistema precisa para se conectar ao Firebase.

  • No menu lateral, clique em "Configurações do projeto" (ícone de engrenagem ⚙️)
  • Role a página até "Seus aplicativos"
  • Clique no ícone </> (Web)
  • Nome do app: sara-makeup-web
  • Clique em "Registrar app"
  • Você verá um código como este:
const firebaseConfig = {
  apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",

Copie cada valor e cole na tela de configuração do admin.html:

Publicar o sistema online (Netlify) — Gratuito

Para que as clientes acessem pelo celular e os dados fiquem sempre disponíveis, vamos publicar o sistema online gratuitamente.

  • Acesse netlify.com e crie uma conta gratuita
  • Clique em "Add new site" → "Deploy manually"
  • Arraste a pasta sara_makeup para a área indicada
  • Aguarde o upload (alguns segundos)
  • Você receberá um link como: sara-makeup.netlify.app
✅ Pronto! Esse link é o endereço da loja. Envie para as clientes!
⚠️ Lembre-se: após publicar no Netlify, abra o admin.html pelo link do Netlify (não pelo arquivo local) para que o Firebase funcione corretamente.

Dúvidas Frequentes

❓ Preciso pagar alguma coisa?
Não! O Firebase tem um plano gratuito (Spark) que suporta até 50.000 leituras e 20.000 escritas por dia — mais do que suficiente para uma loja pequena. O Netlify também é gratuito.


❓ Os dados ficam seguros?
Sim! Os dados ficam nos servidores do Google, com backup automático. Você nunca vai perder nada.


❓ Posso acessar de qualquer celular?
Sim! Tanto o painel admin quanto o catálogo das clientes funcionam em qualquer celular, tablet ou computador com internet.


❓ As clientes precisam criar conta?
Não! As clientes acessam o catálogo sem precisar criar conta. Só preenchem nome e WhatsApp na hora de finalizar o pedido.


❓ Como compartilhar o link da loja?
Após publicar no Netlify, você terá um link como sara-makeup.netlify.app. Envie esse link pelo WhatsApp, Instagram, etc.
